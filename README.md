## 📖 Descripción General

Este proyecto consiste en la landing page oficial de **Toledo Veterinaria**. La plataforma está optimizada para ofrecer una experiencia de navegación fluida tanto en dispositivos móviles como de escritorio, permitiendo a los clientes conocer las instalaciones, agendar citas por WhatsApp y explorar la oferta de servicios de la clínica.

---

## ✨ Funcionalidades Principales

- **Navegación Interactiva:** Menú superior con navegación fluida (*smooth scroll*) hacia cada sección.
- **Catálogo de Servicios:** Muestra detallada de servicios veterinarios, consultas, cirugías y atención especializada.
- **Conexión Directa a WhatsApp:** Botones de llamadas a la acción (*CTA*) integrados para agendar citas de forma rápida.
- **Diseño Responsive:** Adaptabilidad completa para Smartphones, Tablets y Pantallas de Escritorio.
- **Sección de Instalaciones y Equipo:** Presentación de la infraestructura médica y los especialistas.
- **Preguntas Frecuentes (FAQ):** Acordeón interactivo para resolver dudas habituales de los clientes.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica del contenido.
- **CSS3:** Estilos personalizados, variables CSS, layouts flexibles y animaciones.
- **JavaScript (ES6+):** Menú móvil interactivo, control de dropdowns y desplazamiento suave.
- **Google Fonts:** Tipografías *Montserrat* y *Plus Jakarta Sans*.

## 🚀 Instalación y Despliegue

### Ejecutar Localmente

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU-USUARIO/toledo-veterinaria.git
   ```

2. **Acceder al directorio:**
   ```bash
   cd toledo-veterinaria
   ```

3. **Abrir en el navegador:**
   Abre el archivo `index.html` en tu navegador o utilizando *Live Server*.
